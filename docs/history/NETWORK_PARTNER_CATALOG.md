# SOUP Recruitment Network Catalog

This catalog contains 94 unique institutions currently verifiable from public AHZ, GUS/InUni and IEO pages. They are stored as indirect recruitment-network relationships, not falsely represented as direct SOUP contracts.

Networks: AHZ 79 listed institutions; GUS/InUni 8 currently named public recruitment partners; IEO 8 currently named popular partner institutes. Overlaps are deduplicated.

AHZ publicly states 140+ UK partnered universities / 200+ global partners, while GUS states 130+ academic partners; their public pages do not expose every contractual institution name in one complete machine-readable list. The importer therefore only seeds individually verified names. Additional contract rosters should be imported when supplied.
