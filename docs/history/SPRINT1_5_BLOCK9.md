# Sprint 1.5 — Block 9 checkpoint

## Financial & Valuation conversational journey

- Replaced the old financial form/report entry experience with the same modern GCI conversation model.
- The first question determines whether the user is focused on property, a financial-only report, or the integrated GCI + financial product.
- Guest conversation remains available without an account; authentication is triggered only at the first private evidence upload.
- Financial/property documents are processed progressively through the shared evidence pipeline and the result is fed back into the same conversation.
- GCI prompts distinguish document-stated values and evidence from an independent market valuation or legal verification.
- The experience is now designed for repeated property/financial uploads rather than a single generic form submission.
