# SOUP Working v2.1 — Europe & Application Network UI

## Changes
- University detail pages now include a compact right-side **Application network** panel.
- **SOUP / LearnersDen** is always shown as the application-management layer.
- Underlying network routes (AHZ, ApplyBoard, GUS/InUni, IEO, ABN Global, ConnectedHE, EEUA) appear as informational network-access marks only when present in university metadata.
- Network marks are not outbound links; students stay inside SOUP.
- Multiple available routes are deduplicated and displayed together.
- Direct SOUP/LearnersDen institutions show only SOUP / LearnersDen.
- Homepage university feature grid is Europe-led with deliberate priority for University of Debrecen, IBS Budapest, KEDGE, ESDES, University of Europe for Applied Sciences, University of Greenwich, Dublin Business School and Hochschule Fresenius when present in the seeded database.
- University directory sorts European institutions first while retaining all other regions.
- Noodles now defaults to suitable European SOUP-network options when the student has no geographic preference, without overriding student constraints or suitability.
